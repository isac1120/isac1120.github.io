  • 맞춤 NMPC를 적용해 실시한 테스트에서 사행과 목표 위치·자세 도달 문제를 해결했습니다.
  • Python 기반 solver 관련 구현을 C++로 옮기고 불필요한 최적화 변수를 줄였습니다.

RC car 자율주행 테스트 플랫폼

  • 펌웨어와 실제 서보 설정의 불일치를 수정하고 CAN 통신·센서·구동부를 ROS 2 시스템에 통합했습니다.
  • Mapping·navigation 실험을 위한 플랫폼을 구축하고 후속 로봇학습 실험에도 활용했습니다.

단일 ACT 정책으로 접근·정렬·복귀

  • 파레트 적재를 모사한 여섯 배치 유형별 시연 데이터를 구성하고 ACT 정책을 학습했습니다.
  • 동일 모델에 0/1 명령으로 접근·정렬과 복귀를 지정해 RC car에서 실행했습니다.
  • 속도 관측을 포함했을 때 편향이 지속되는 현상을 확인하고, RGB 기반 관측으로 변경해 의도한 동작을 확인했습니다.
  • SmolVLA와 ACT를 비교하고 사용한 온보드 환경의 실행 속도와 동작을 기준으로 ACT를 선택했습니다.

로봇팔 비전 기반 제어

  • Scaramuzza 왜곡 보정과 hand–eye calibration을 구현하고, MATLAB 구현과의 파라미터 비교·좌표 변환 순서 수정·보정 이미지 개선으로 결과를 검증했습니다.
  • 카메라의 AprilTag 관측을 로봇 API에 연결해 정면 자세와 일정 거리를 유지하는 추종 프로그램을 개발했습니다.

AMR 모터 제어 드라이버

  • CANopen 기반 모터 제어 드라이버 프로그램을 구현했습니다.
